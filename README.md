# PayRec — 법인카드 식대·택시 기록

1인당 일 한도(기본 20,000원) 법인카드를 한 사람이 대표 결제할 때, **누구와 함께 사용했는지**를 기록하고 월말 결재용 내역을 만드는 웹앱(PWA)입니다. 설치·서버·빌드가 필요 없는 정적 파일로 구성되어 있습니다.

## 기능

| 구분 | 내용 |
|---|---|
| 날짜 선택 | 기본값 오늘, 과거 날짜 입력 가능 |
| 인원 선택 | 한 번 추가한 이름은 선택지에 유지, 즉석 추가 가능. 설정에서 "기본" 지정 시 자동 선택(본인 등) |
| 잔액 계산 | 선택 인원 × 1인 한도 = 최대 금액, 입력 금액과의 차액(잔액/초과) 실시간 표시 |
| 택시 | 식대 한도와 분리하여 별도 기록·합계 |
| 자동 입력 | 결제 알림 문자 붙여넣기 → 금액·날짜·가맹점 인식 / URL 파라미터로 값 전달 |
| 월별 내역 | 식대·택시 분리 합계, 일자별 표, 인원별 이용 일수, CSV(엑셀) 저장, 인쇄/PDF |
| 데이터 보존 | 브라우저 저장소(영구 저장 요청) + JSON 백업/복원 |

## 사용 방법

1. GitHub 저장소 **Settings → Pages**에서 배포할 브랜치와 `/ (root)` 폴더를 선택합니다.
   (비공개 저장소의 Pages 사용 가능 여부는 GitHub 요금제에 따라 다릅니다.)
2. 휴대폰에서 배포 주소를 열고 **홈 화면에 추가**합니다(iOS Safari: 공유 → 홈 화면에 추가 / Android Chrome: 메뉴 → 앱 설치).
3. 로컬 확인: `python3 -m http.server` 실행 후 `http://localhost:8000` 접속.

## 결제 알림 자동 연동(선택)

웹앱은 보안상 다른 앱의 알림·문자를 직접 읽을 수 없습니다. 아래 방법 중 하나를 사용합니다.

- **붙여넣기**: 카드사 승인 문자를 복사 → 입력 화면 "결제 알림 문자 붙여넣기" → 금액·날짜 인식
- **URL 파라미터**: 자동화 도구(안드로이드 Tasker/MacroDroid 등의 알림 감지, iOS 단축어)가 아래 주소를 열도록 설정

```
https://<배포주소>/?amount=64000&memo=식당명
https://<배포주소>/?text=<승인 문자 전문(URL 인코딩)>
https://<배포주소>/?type=taxi&amount=23400
```

## 데이터 관련 유의사항

- 데이터는 해당 기기·브라우저에만 저장됩니다. 브라우저 데이터 삭제, 기기 변경 시 소실될 수 있으므로 **설정 → 백업 파일 저장**을 월 1회 이상 수행하십시오.
- 기존 기록의 인원 이름은 기록 시점의 이름으로 보존되며, 선택지에서 삭제해도 과거 기록은 유지됩니다.
